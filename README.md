# GitHub Practice

## Purpose
-This repository is created to practice and understand the basic use of Git and GitHub.

## Git and GitHub
-Git is a version control system that tracks changes in files and helps developers manage their projects. GitHub is an online platform where developers can store, share, and collaborate on Git repositories. They work together by allowing users to track their code changes locally and upload them to an online repository.

## Commit
-A commit records the changes made to files in a repository at a specific point in time.
